Версия SQLite: 3.53.4

Режимы вывода данных (команда .mode в sqlite3):
- ascii    — значения, разделённые символами 0x1F (между столбцами) и 0x1E (между строками)
- box      — таблица с использованием символов псевдографики Unicode
- csv      — значения, разделённые запятыми (Comma-Separated Values)
- column   — колонки, выровненные по ширине
- html     — вывод в виде HTML-таблицы <table>
- insert   — SQL-инструкции INSERT для указанной таблицы
- json     — вывод в формате JSON
- line     — одно значение на строку
- list     — значения, разделённые разделителем (по умолчанию "|")
- markdown — вывод в формате Markdown-таблицы
- qbox     — сокращение для "box --wrap 60 --wrap-char +"
- quote    — экранирование значений как в SQL-литералах
- table    — ASCII-таблица
- tabs     — значения, разделённые табуляцией
- tcl      — элементы TCL-списка
