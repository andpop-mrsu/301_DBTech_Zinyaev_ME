# Task01

## Структура файлов данных

- `ratings.csv` — исходные данные оценок пользователей.
  Колонки: `userId`, `movieId`, `rating`, `timestamp`.
- `ratings_count.txt` — количество строк для минимального и максимального `userId`.
- `sqlite.txt` — версия SQLite и доступные режимы вывода.
- `README.md` — этот файл с описанием.
